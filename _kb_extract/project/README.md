# UMKM Inventori & Finansial - Web App

Aplikasi Flask yang menggantikan spreadsheet `Sheet_Inventori_dan_Finansial_UMKM.xlsx`.

**Mulai cepat:**
```bash
pip install -r requirements.txt
python seed_data.py   # opsional, isi data contoh
python app.py
```
Lalu buka `http://localhost:5000`.

Dokumentasi lengkap (struktur project, ERD, flowchart, pemetaan rumus, catatan
keamanan, dan status pengujian yang sudah/belum dilakukan) ada di
[`docs/README.md`](docs/README.md). **Sangat disarankan membaca bagian
"Status pengujian" di sana sebelum menganggap aplikasi ini siap produksi.**
